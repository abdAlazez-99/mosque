# 🕌 Mosque Website

A clean, modern, and responsive web application designed for a mosque community. This project serves as a digital platform to share prayer times, announcements, events, and essential information for community members.

🔗 **Live Demo:** [View Website](https://abdalazez-99.github.io/mosque/)

---

## ✨ Features & Highlights

- **Responsive Design:** Fully optimized layout that adapts seamlessly to desktops, tablets, and mobile devices.
- **Community Focused:** Structured to easily display prayer schedules, upcoming events, and announcements.
- **Clean & Modern UI:** Built with structured HTML and clean styling for a peaceful and professional aesthetic.
- **Lightweight & Fast:** Optimized assets ensuring quick loading times directly via GitHub Pages.
